# 墨水屏日历 网页使用说明

本工具用于设置墨水屏电子价签日历：连接设备、显示日历、导入节假日，上传图片。

在线打开：[https://breeze4dev.github.io/epd-noclock](https://breeze4dev.github.io/epd-noclock)

---

## 适用设备与浏览器

- 支持本项目配套的图片轮播固件的价签。
- 推荐浏览器：
  - 电脑：Chrome / Edge
  - Android：Chrome / Edge
  - iOS：Bluefy（系统自带浏览器一般无法使用蓝牙）

请打开网页后保持手机或电脑的蓝牙已开启。

---

## 连接设备

1. 打开网址：[https://breeze4dev.github.io/epd-noclock](https://breeze4dev.github.io/epd-noclock)。
2. 点 **连接**，在弹出列表里选择价签设备。
3. 连接成功后，页面会显示设备状态。

如果搜不到设备：先在价签上 **长按按键** 打开蓝牙，灯亮后再点连接。连接后可用 **重连** 快速再次连接。

---

## 日历

点 **日历模式**，会把手机/电脑的时间同步到价签，并刷新成当天日历（含农历、节气等）。

刷屏大约需要十几秒，完成前请不要断开或反复点击。

**清除屏幕** 会把当前画面清掉，清屏同样需要等待刷新结束。

### 蓝牙常开

- **不勾选（默认）**：平时蓝牙关闭，需要长按按键才会被电脑搜到，更省电。
- **勾选**：上电后蓝牙一直可被连接，使用更方便，耗电会多一些。

设置会保存在设备里，断电后仍然有效。

### 节假日 / 调休

日历上的「休」「班」来自调休数据。

1. 选择年份。
2. 点 **从 GitHub 导入**，自动下载该年的中国大陆调休安排。
3. 也可点 **导入 JSON**，使用自己准备的年份数据。
4. **恢复固件默认** 会清掉导入内容，改回出厂数据。

导入后，再点一次 **日历模式** 即可按新数据显示。

## 传图



### 准备画面

1. 选择一张图片（支持常见的 png、jpg、bmp、webp）。
2. 若图片比例和屏幕不一致，会进入裁剪：可放大、缩小、移动，点 **完成** 确认。
3. 可调整 **抖动算法、强度、对比度**，让照片在黑白红墨水屏上更清晰。
4. 需要时可 **旋转画布** 或 **清除画布**。

画布下方工具：

- 画笔、橡皮擦：在图上涂改
- 文字：输入内容后点「添加文字」，再点画布放置；可改字体、大小、粗体、斜体
- 上一步 / 下一步：撤销或重做（也可使用 Ctrl+Z / Ctrl+Y）

三色屏建议选用红色、黑色、白色；其他颜色传到屏上会被近似成这三种。

### 发到屏幕（不保存）

点 **发送到屏幕(不存储)**：立刻刷新当前画面，设备断电或切回日历后，这张图不会保留。

传图和刷屏过程中请保持连接，不要离开网页。

### 保存到槽位

连接成功后会出现 **图片槽位**。槽位从 **1** 开始编号，用来在设备里存多张图。

常用操作：


| 按钮          | 作用                |
| ----------- | ----------------- |
| 刷新槽位        | 读取设备里已有的图片        |
| 发送到槽位并显示    | 把当前画布存进选中的槽，并立刻显示 |
| 显示此槽        | 把该槽的图刷到屏幕上        |
| 读取图片        | 把槽里的图读回网页缩略图      |
| 显示到画布       | 把已读取的图放到画布上再编辑    |
| 删除此槽 / 清空全部 | 删除一张或全部已存图片       |
| 新增槽位        | 展开后面的空槽（空槽默认会收起来） |


先点选一个槽位（如「槽1」），再发送或显示。

### 轮播

多张图存好后，可设置自动换图：

1. 填写间隔（**0 为关闭**，最短 **5 分钟**，也可按小时设置）。
2. 选择 **随机** 或 **顺序**。
3. 点 **设置轮播**。

轮播时设备会按间隔自动切换已保存的图片。

---



## 使用注意

- 墨水屏每次刷新都需要一段时间，进度条走完或屏幕画面稳定前，请不要连续操作。
- 传图时请靠近设备，避免蓝牙中断导致画面不完整。
- 日历和图片可以随时切换：点「日历模式」回日历，点「显示此槽」或「发送到屏幕」看图片。
